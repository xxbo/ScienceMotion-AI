## Gate R — Minimum local reliability

The host and local F integration passed the exact integrated CI run #43783296488. The reliability evidence is recorded below.

- [x] Concurrent identical idempotent calls cause one tested project mutation; same key with different input is rejected both while pending and after completion. Record ownership and concurrency reservations are released correctly on failures.
- [x] Persisted execution evidence survives restart. Interrupted or uncertain work is explicit and cannot masquerade as success; document replay/recovery boundaries without claiming distributed exactly-once execution.
- [x] Test cancellation before execution, during storage admission and during a running call, plus timeout behavior. Host execution/policy failures produce inspectable diagnostics.
- [x] In-use asset removal is rejected or performs an explicit valid cascade. Project/reference commit failures recover conservatively; assets needed by another project or retained snapshot remain available after GC and restore.
- [x] Reconciliation handles changed content under the same asset ID and URI/hash conflicts. Unsupported animation/capabilities are diagnosed rather than silently changed.
- [x] The host uses an explicit permission allow-list and bounded invocation limits. Destructive/high-cost operations require approval or are unavailable in this first workflow.

## Gate I — Programmatic inspection and repair

- [x] Expose read-only inspection through public discovery/invocation with ownership/hash validation, grants and bounded frames/work/output.
- [x] Return versioned snapshot/revision evidence, grouped issues, affected nodes/tracks/scenes and exact checked frames. Disclose sampling, truncation and unchecked domains; a model-only result is not a final-video pass.
- [x] Reuse model diagnostics and declared shape/chart bounds. Detect and repair intermediate-frame motion through public tools without rendering; old-snapshot and restart reports remain stable.
- [x] Measure actual browser text/layout after fonts load in the production composition; diagnose seeded overflow/crop/default-prop errors with measured evidence.
- [ ] Run inspection/repair on both fixtures, record costs and detected/missed seeded defects, and retain pixel checks and human visual review. Intentional overlap/offscreen motion must be distinguishable from unconditional failures.

I1 evidence is described in [Snapshot inspection](P1.1-G-INSPECTION.md); I2 in [Browser layout inspection](P1.1-G-LAYOUT.md). The [two-topic scenario](P1.1-CREATIVE-LOOP.md) now performs inspection/repair on both fixtures, records wall times, detects all four deliberately seeded defect instances and preserves pixel checks. Both inspectors report viewport crossings as warnings, because intentional exits are valid. The last item stays open for human review, deferred by the user until final acceptance. Deterministic regression is not the real-AI trial.

## Gate C — Actual creation, editing and restoration

- [x] From an empty project, discover manifests and use tools to build text, shapes and animation, commit a snapshot, inspect structured diagnostics, render a preview and export a video. Verify project/schema/revision/Artifact integrity at each boundary. The host render smoke covers the production snapshot-to-PNG/MP4 path.
- [x] Produce two different-topic short fixtures (target 10–30 seconds each), for example CPU/cache data flow and a water-cycle diagram. Both use the same tool/renderer implementation and data-driven content; no new topic-specific TSX scene is added.
- [x] Change one identified object's text/position and one animation property via tools. Assert the expected sampled values and meaningful pixel/frame changes; check unrelated project nodes/approved content remain unchanged.
- [x] Save, restart the local host, restore and render again. Compare canonical data, asset hashes and declared frame tolerances; do not assume byte-identical MP4s across different rendering environments.
- [ ] Test a failing mutation, a safe retry and a plugin version switch within the integrated path, including a failed upgrade that preserves the previous usable implementation.

Both 12-second fixtures reject a stale revision without mutation, replay the valid edit without duplicate revisions before/after restart, replace a real brief data dependency and restore its original hash/bytes. The last item remains open because plugin-manager version tests do not establish a switch through the production Creative Host workflow.

## Gate Q — Technical and visual quality

- [x] Automated output checks cover streams, expected dimensions/FPS/duration and integrity. For fixtures with narration, verify audio presence and record an audio/caption synchronization review.
- [ ] Sample start/middle/end and significant keyframes. Record review of approved text, legibility, clipping, accidental overlap and motion timing. Automated checks and human visual review are reported separately.
- [x] Render evidence identifies project revision/snapshot hash, exact tool/plugin choices, adapter version, render profile, output hashes and diagnostics. Preserve before/after previews for the targeted edit.

The two acceptance fixtures are explicitly silent. CI fully decodes all six baseline/edited/restored MP4s, checks 960×540, 30 FPS, 360 frames / 12 seconds and black intervals, and preserves 18 PNG previews. This does not close narration/caption synchronization or final presentation review. The separately published narrated CPU-cache sample remains a comparison reference, not proof of those remaining checks.

These gates establish a usable initial 2D subset, not advanced 3D, physics simulation or final long-form production quality.
