# P1.1-G — Data-driven Chart Tool

## Tool surface

`graphics.2d.chart.create` creates a Project Graph chart node. It supports bar and line charts, 2–24 labelled numeric values, configurable dimensions, series color, label color and font size. Values may be positive, zero or negative.

## Architecture

Chart data is stored in a geometry component as structured JSON. The generic Project Graph render model validates it and emits a renderer-neutral chart element. Remotion renders axes, grid lines, values, category labels, bars or line markers from that element. The same tool and composition work for different subjects and datasets.

`ProjectGraphFrame` dispatches chart elements to `ProjectChartSvg`, which shares the node's composed transform, opacity and drawing order. Bar heights extend from zero in the correct direction. Line points preserve input order. All-zero series have a non-degenerate scale and zero-height bars. Values are normalized before computing the scale so finite mixed-sign values near `Number.MAX_VALUE` do not overflow.

The generic Remotion composition's default props contain only the demo project, not its scene-selection hint. Previously, Remotion's input/default merging could retain `scene-water-cycle` when a caller supplied a different project without `sceneId`, producing a blank frame. Snapshot rendering now follows the supplied project's timeline unless the caller explicitly selects a scene. The chart smoke scenario intentionally omits `sceneId` and detects this regression through output pixels.

The SVG includes a zero axis, grid/tick labels and series/category labels. On small or dense charts, visible value/category labels are sampled and long category labels are shortened; every bar/point remains present, and full labels/values remain in SVG titles and its accessible description. Numeric display labels are compact; source values remain unchanged. Rich label layout is later work.

## Validation

The tool schema and implementation enforce a bounded number of points, non-empty bounded labels and finite numeric values. The renderer repeats validation for persisted/imported documents and emits `RENDER_INVALID_CHART_DATA` diagnostics on invalid content.

## Tests

Unit tests verify structured chart projection and invalid-data diagnostics. Creative Host integration creates a chart using the public Gateway tool and confirms the render model consumes the resulting ProjectDocument.

`project-chart-render.test.ts` additionally renders the actual frame component to markup. Four regression cases cover signed bars/zero baselines, connected line points, all-zero/negative-only/extreme numeric data, and dense escaped labels. All four failed against the previous shape fallback before the chart drawing branch was added.

Run `npm run render:chart-smoke` after installing the Remotion browser and FFmpeg. This production-host scenario uses public tools to create both charts, save snapshots, render PNG previews and export a one-second 1280×720/30 FPS MP4. FFmpeg decodes actual output pixels: checks reject filled-rectangle fallbacks, verify that changing one bar value from 12 to 0 removes that bar, and compare the unrelated line-chart region byte for byte. MP4 checks cover metadata and chart-colored pixels in a decoded frame.

CI runs this check and uploads `charts-before.png`, `charts-after.png`, `charts-video.mp4` and `chart-render-evidence.json`. The JSON records snapshots, Artifact identities/provenance and pixel-check results. This chart-specific regression does not close two-topic, restart/restore, real-AI or general visual-quality acceptance gates.

## Local verification — 2026-11-16

Type checking, all 185 platform tests, Episode/Project/Patch/tool/plugin validators and SVG storyboard generation passed. The production chart smoke passed with 23,232 series-colored bar pixels and 536 line pixels in the initial PNG, a removed positive bar after the edit, and an unchanged line-chart region. The one-second MP4 passed stream/profile and decoded-pixel checks. Assistant inspection of the two PNGs confirmed readable Chinese headings/categories and visible signed bars/line points; this is not the human review required to close Gate Q. Exact remote validation is attached to the change's CI run.
