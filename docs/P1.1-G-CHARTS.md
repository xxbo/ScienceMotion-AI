# P1.1-G — Data-driven Chart Tool

## Tool surface

`graphics.2d.chart.create` creates a Project Graph chart node. It supports bar and line charts, 2–24 labelled numeric values, configurable dimensions, series color, label color and font size. Values may be positive, zero or negative.

## Architecture

Chart data is stored in a geometry component as structured JSON. The generic Project Graph render model validates it and emits a renderer-neutral chart element. Remotion renders axes, grid lines, values, category labels, bars or line markers from that element. The same tool and composition work for different subjects and datasets.

## Validation

The tool schema and implementation enforce a bounded number of points, non-empty bounded labels and finite numeric values. The renderer repeats validation for persisted/imported documents and emits `RENDER_INVALID_CHART_DATA` diagnostics on invalid content.

## Tests

Unit tests verify structured chart projection and invalid-data diagnostics. Creative Host integration creates a chart using the public Gateway tool and confirms the render model consumes the resulting ProjectDocument.
