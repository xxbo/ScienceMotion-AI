# P1.1-G — First Project Graph Creative Slice

## Delivered

- A renderer-neutral frame projection selects the active scene/shot and evaluates supported Project Animation Tracks.
- The initial Remotion adapter renders text, rectangles, circles, ellipses, lines and nested group transforms, including opacity and supported keyframe sampling.
- Unsupported node/animation capabilities return structured diagnostics from the render model.
- The Episode/CPU-cache composition remains unchanged and independently registered.
- The built-in workspace plugin adds executable tools for scene/shot creation, 2D text, 2D shapes, node transforms and keyframe tracks. All mutations use Patch 1.3.0 through the scoped host services and canonical repository.
- A data-driven water-cycle Project Graph fixture is rendered by CI as a 10-second 1080p/30fps MP4 and checked with ffprobe.
- Host integration tests create and edit a project exclusively through Gateway tools, then feed the resulting ProjectDocument into the generic render projection.

## Initial 2D capability boundary

Supported: text, basic geometric primitives, scene/shot selection, 2D translation/rotation/scale, nested group transform composition, opacity and linear/step/cubic-bezier keyframe sampling.

Not yet supported by this adapter: paths/SVG, rich text layout, font asset resolution, masks, gradients, materials, camera projection, 3D mesh, lighting, physics, audio/caption tracks, transitions, renderer-side artifact creation and visual inspection. The model returns warnings/errors for unsupported node and animation cases.
