# P1.1-G — Structured SVG Path Tool\n\n## Tool\n\n`graphics.2d.path.create` creates a Project Graph node of type `path`. Inputs include scene/node identity, path command data, local position, viewport dimensions, fill, stroke, stroke width and fill rule. The operation is committed through the normal Patch 1.3.0 project editing boundary.\n\n## Safety and portability\n\nThe input accepts SVG path commands and numeric parameters only. Raw `<svg>` documents, XML elements/attributes, CSS, URLs and script-bearing markup are rejected. The Project Graph stores the path as structured geometry data; the Remotion adapter renders it with a native SVG path element. No generated TSX or topic-specific renderer component is introduced.\n\n## Rendering and tests\n\nPath nodes share the existing hierarchy transform and opacity composition. The adapter supports the standard M/L/H/V/C/S/Q/T/A/Z path command alphabet, fill rules, fill, stroke and stroke width. Unit coverage verifies a cubic Bézier closed path is projected and markup payloads produce an invalid-path diagnostic. Host integration creates a path through the public Gateway tool and confirms unsafe markup is rejected.\n
